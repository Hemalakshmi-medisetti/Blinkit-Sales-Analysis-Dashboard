🛒 Blinkit Sales Analysis Dashboard | Power BI

📌 Project Overview

This project focuses on analyzing Blinkit sales data using Microsoft Power BI. I created an interactive dashboard to explore sales performance, product trends, and customer ratings through meaningful visualizations.

🎯 Project Objectives

- Analyze overall sales performance.
- Understand item-wise sales distribution.
- Identify key business insights.
- Visualize sales trends using interactive charts.

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning and Transformation

📊 Dashboard Features

- Total Sales Analysis – Understand overall sales performance.
- Average Sales Analysis – Analyze average sales.
- Average Rating Analysis – Understand customer ratings.
- Item-wise Sales Analysis – Compare sales across different item categories.
- Interactive Visualizations – Explore the data through dashboard filters and charts.
